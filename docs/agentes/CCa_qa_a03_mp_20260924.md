## Riesgos / pendientes

1. **Import bloqueante:** `from universo_fechas import clasificar_fecha` va a lanzar `ImportError` en cuanto se llame a `obtener_comprometido_por_codigo` o `comprometido_detalle` hasta que el módulo exista en el mismo nivel que `motor_v2.py`. Puse el import dentro de la función (no a nivel de módulo) para que el resto de `database_cubigest.py` (usado por Programación, Vista Semanal, etc.) no se rompa mientras tanto — pero **la sección Materia Prima quedará caída (500) hasta integrar `universo_fechas.py`**. Necesito que la Coordinadora confirme el path/nombre real del módulo cuando la ventana hermana lo termine, para verificar que el import literal (`from universo_fechas import clasificar_fecha`, mismo nivel que `motor_v2.py` = raíz de `backend/`) es correcto.
2. **Leyenda "sin fecha confirmada" (sección 3/4 del spec):** no implementé el conteo/leyenda "N ITs / X.XXX kg fuera" en la UI. `obtener_comprometido_por_codigo` sigue devolviendo `dict[str, float]` (mismo contrato que antes) para no romper `materias_primas.py`/`GestorMatPrima.tsx` sin coordinar — la exclusión ya no infla la demanda, pero el jefe de planta no ve todavía por qué bajó el número. Falta decidir con Montu/Coordinadora si esto se expone como campo nuevo en la respuesta del endpoint (cambia el contrato con el frontend, fuera de mi territorio asignado) o como endpoint aparte.
3. **`TotalKgs` vs `KgsPaquete`:** mantuve `SUM(p.TotalKgs)` (por Pieza, no por paquete) para minimizar el cambio — el filtro de avance descarta la Pieza completa si su paquete ya llegó a 100%, no hace prorrateo parcial. Si una Pieza tiene múltiples paquetes con avances mixtos (algunos 100%, otros no), esto puede sub- o sobre-contar levemente esa Pieza puntual. No until pude cuantificar cuántos casos tienen avance mixto entre paquetes de una misma Pieza — dato para verificar cuando universo_fechas esté integrado y se pueda correr end-to-end con más tiempo.
4. Confirmar con Montu si `horizonte_reprog` debe calcularse con `MAX(FechaMod)` (última reprogramación, lo que usé) o `MIN(FechaOriginal)` — la sección 2 del spec dice "fecha de despacho − fecha de última reprogramación", que interpreté como `MAX(FechaMod)`.
